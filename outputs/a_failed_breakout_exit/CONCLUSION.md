# 结论先读

**保留实验记录，不建议把A_FAIL_EXIT纳入正式策略或替换A_BASE。** 它确实减少了失败交易损失，但会误杀赢家，完整账户没有跨年份一致改善。没有追加其他持仓小时、带内条件或参数。
