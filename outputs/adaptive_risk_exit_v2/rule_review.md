# 独立只读规则审查

已检查V2、原VariantSleeve、AuditSleeve和逐笔事件链，未发现阻断问题：

- check在每分钟边界、当分钟真实成交前调用；15分钟边界只取之前两根已完成K线和已有止损，无使用本根未来高低点。
- 原cash开仓不扣保证金，仅在实际已实现盈亏时credit；因此预算使用本币已实现账面余额，不把可用保证金或浮盈混进余额。
- 请求固定数量并在入队时设置当前Position的一次性标志，下一真实成交不重算；标志不会传给下一笔持仓。
- VariantSleeve先执行原止损，再处理减仓队列。V2直接继承VariantSleeve，避免旧Dynamic的stage2过时标签。
- 整数步长取整、初始量25%上限、至少保留一个步长、不加回均已落实。

解释边界：首次弱势检查没有可减量时不消耗机会，后来可以触发首次减仓；一次性规则禁止的是后续追加。余额按每年每币500重新起跑，只在年内随已实现收益变化。参考风险是从闭合价格回吐到当前有效止损的距离，不是从开仓价计算的亏损上限，也不是账户最大回撤保证。

审查不替代真实历史运行和金融回归测试，其结果分别在report.md与test_results.json。
