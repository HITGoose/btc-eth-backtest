# 实施与归因说明
- 与A_BASE仅有未成交撤单差异，无A_FAIL_EXIT、V2、动态仓位或新入场。原源码、main和旧结果不修改。
- T+60先原到期、再取消仍有效的同一订单、再价格撮合；此前成交的9次请求失效，22次请求原到期先执行，不能记成132次实际撤单之外的成功撤单。
- 24次实际取消的变体订单没有基准同身份提交，单列BASE_NO_SUBMITTED_ORDER并保留未知对照；不是“基准最终未成交”。73次基准确实已提交但截至区间结束未成交，包含原到期/期末挂单，实际成交名义不存在，r1000留空。
- 原Counter不保存未被访问的0值，初次报告遇无撤单账户缺stale_cancelled键；仅将报告读取改为缺省0，金融执行没有改动或重跑。取消守恒单列stale_cancelled，不伪记为expired。
- 35个直接撤单且基准成交的身份中，17亏18赢；其原净额整体为正。另15笔原成交因后续订单/占仓路径消失，不能算直接撤销；52笔新增已平净亏，不把归因当成账户净增益。
- “等待较长”由基准实际提交至成交计算；未成交不以60分钟TTL冒充等待。基准存在但变体未提交的33个订单单列，不混作保留订单。
- 2024BTC329天持仓在8.5分钟已成交，无后续未成交检查，未取消、两费用结果与基准相同；没有为保留它修改条件。
- 1m OHLC假设不是RAW；两费用并非独立样本，Maker0.02%不是核实账户费率，资金费0。各年独立，不拼接跨年复利；已见历史不称样本外。
